# Site E-commerce

Projeto escolar de um site de e-commerce fictício, desenvolvido com o apoio de Inteligência Artificial durante o processo de criação.

## 📋 Sobre o projeto

O **Voltz N' Velvet** é uma loja virtual criada como projeto acadêmico, simulando as principais páginas e funcionalidades de um site de vendas online: catálogo de produtos, busca, informações sobre a loja, pedidos e contato.

## 🛠️ Tecnologias utilizadas

- **HTML** — estrutura das páginas
- **CSS** — estilização visual

## 📄 Páginas do site

- `index.html` — Página inicial
- `produtos.html` / `produto.html` — Catálogo e detalhes de produtos
- `pesquisa.html` — Busca de produtos
- `about.html` — Sobre a loja
- `orders.html` — Pedidos
- `contato.html` — Contato
- `signup.html` — Cadastro

## 🎓 Contexto

Este projeto foi desenvolvido como trabalho escolar, com o objetivo de praticar conceitos de desenvolvimento web e estruturação de sites, utilizando ferramentas de IA como apoio no processo de criação.
